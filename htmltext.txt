Html design of docs.

<!doctype html>                     // always used, historical?
<html lang="en-US">                 // <html> </html> wraps the page ie the whole pages contents.
  <head>                            // Element container for info the users dont see, keywords, desc for searching?
    <meta charset="utf-8" />        // meta data? sets up all languages to be useable in the page?
    <title>My test page</title>    // Title that appears in the website address. blabla.com
  </head>                           
  <body>                           // Everthing thats shown in the page.
    <p>This is my page</p>
  </body>
</html>
