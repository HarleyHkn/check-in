CSS Cheatsheet: Basic Styling Commands & Properties (With Code Examples, Classes, & Full Mockup)

=== Core Concept: How CSS Works & Targeting Specific Segments ===
1. Structure of a CSS Rule:
   selector {
       property: value;
   }
   - Selector: Targets the HTML element (e.g., p, h1, or a class like .special).
   - Property: What you want to change (e.g., color, font-size).
   - Value: The setting for that property (e.g., red, 20px).

2. How to Use Classes to Target Specific Segments:
   - Step 1 (HTML): Give your specific element a name using the class attribute (e.g., <p class="my-special-box">Hello</p>).
   - Step 2 (CSS): In your CSS file, target that exact name by putting a dot (.) in front of it (e.g., .my-special-box { color: red; }).


=== Basic Text Styling Commands ===

1. color
   - What it does: Changes the text color.
   - Code Example:
     .my-text {
         color: blue;
     }

2. font-size
   - What it does: Changes how big or small the text is.
   - Code Example:
     .large-heading {
         font-size: 32px;
     }

3. font-family
   - What it does: Changes the font style/typeface.
   - Code Example:
     .custom-font {
         font-family: sans-serif;
     }

4. font-weight
   - What it does: Changes how thick or bold the text is.
   - Code Example:
     .bold-text {
         font-weight: bold;
     }

5. text-align
   - What it does: Aligns text to the left, right, center, or justified.
   - Code Example:
     .centered-title {
         text-align: center;
     }


=== Basic Layout & Box Styling Commands ===

1. background-color
   - What it does: Changes the background color behind an element.
   - Code Example:
     .highlight-bg {
         background-color: yellow;
     }

2. width & height
   - What it does: Sets the size of an element's box.
   - Code Example:
     .banner-img {
         width: 200px;
         height: 100px;
     }

3. padding
   - What it does: Adds space *inside* the element, between the content and its border.
   - Code Example:
     .padded-box {
         padding: 15px;
     }

4. margin
   - What it does: Adds space *outside* the element, pushing other elements away.
   - Code Example:
     .spaced-paragraph {
         margin: 20px;
     }

5. border
   - What it does: Adds an outline around an element.
   - Code Example:
     .bordered-box {
         border: 2px solid black;
     }


=== Complete Mockup Example: Putting HTML and CSS Together ===

Here is what a complete setup looks like when you combine your CSS file and your HTML file using classes:

--- style.css (Your Design File) ---
body {
    font-family: sans-serif;
    background-color: #130c3d09;
}

.large-heading {
    font-size: 32px;
    color: darkblue;
    text-align: center;
}

.highlight-bg {
    background-color: yellow;
    padding: 10px;
}

.bordered-box {
    border: 2px solid black;
    margin: 20px;
    padding: 15px;
}


--- index.html (Your Web Page File) ---
<!doctype html>
<html lang="en-US">
  <head>
    <meta charset="utf-8" />
    <title>My Styled Page</title>
    <link rel="stylesheet" href="style.css" />
  </head>
  <body>
    <!-- Uses the .large-heading class to style just this h1 -->
    <h1 class="large-heading">Welcome to Velmo & Co.</h1>
    
    <!-- Uses the .bordered-box and .highlight-bg classes -->
    <div class="bordered-box">
        <p>This is a regular paragraph.</p>
        <p class="highlight-bg">This specific paragraph has a yellow background highlight.</p>
    </div>
  </body>
</html>
