CSS (Cascading Style Sheets)
Basicly its designing ur html so the page isnt just straight up white and black text.



CSS is a rule-based language — you define rules by specifying groups of styles 
that should be applied to a particular element or groups of elements on your web page.

Example
gives h1 red color and fontsize.
and p same thing different color, paddin etc.


h1 {
  color: red;
  font-size: 2.5em;
}

p {
  color: aqua;
  padding: 5px;
  background: midnightblue;
}

To connect css to an html document u need to input this into the header <head>
<link rel="stylesheet" href="styles.css" />             // href it to the docs name.

could be placed in different places

<!-- In a subdirectory called styles in the current directory -->
<link rel="stylesheet" href="styles/style.css" />

<!-- In a subdirectory called general, which is in a subdirectory called styles, in the current directory -->
<link rel="stylesheet" href="styles/general/style.css" />

<!-- Go back one directory level, then in a subdirectory called styles -->
<link rel="stylesheet" href="../styles/style.css" />
